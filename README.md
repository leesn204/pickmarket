# 픽마켓 릴스 쇼핑형 2.0

## 파일
- `index.html`: 방문자용 쇼핑몰
- `products.json`: 공개 상품 데이터
- `admin.html`: **운영자 컴퓨터에서만 사용하는 로컬 편집 도구. 공개 배포 금지**

## 무료 배포 (GitHub Pages)
1. GitHub에서 새 공개 저장소 `pickmarket` 생성.
2. 저장소 최상위에 `index.html`과 `products.json` **두 파일만** 업로드 후 Commit.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. 수 분 후 표시되는 `https://계정명.github.io/pickmarket/` 주소로 접속. GitHub Pages 활성화/반영에 시간이 걸릴 수 있습니다.
5. 릴스 프로필에 해당 주소를 입력합니다.

## 상품 관리
1. 압축 파일을 본인 컴퓨터에 보관합니다. 공개 저장소에는 `admin.html`을 업로드하지 마세요.
2. `admin.html`을 브라우저에서 엽니다.
3. `products.json 불러오기`로 현재 공개 저장소의 products.json 사본을 불러옵니다.
4. 상품을 추가·수정·삭제하고 `products.json 다운로드`를 누릅니다.
5. GitHub 저장소의 `products.json`을 새 파일 내용으로 교체 후 Commit합니다. 몇 분 뒤 공개 사이트에 반영됩니다.
6. 관리자 로그인/클라우드 DB/자동 게시 기능은 **미구현**입니다. GitHub 계정 접근 권한으로 공개 파일의 변경 권한을 관리합니다.

## 영상
- 영상 필드에는 본인이 권리를 보유하거나 사용 허가를 받은 **직접 재생 가능한 HTTPS MP4 URL**을 넣으세요.
- 인스타그램 릴스 링크나 YouTube Shorts 페이지 URL은 MP4 URL이 아닙니다. 직접 재생되지 않습니다.
- 영상은 별도 호스팅이 필요합니다. GitHub Pages 저장소에 큰 동영상을 계속 올리는 방식은 권장하지 않습니다. 영상 URL이 없으면 '영상' 버튼은 비활성화됩니다.
- 이미지도 사용 권한을 확인하고 HTTPS 이미지 URL을 사용하세요.

## 제휴 및 운영 주의
- 쿠팡파트너스에서 본인 계정으로 생성한 상품별 제휴 URL을 등록하세요. 실제 제휴 정책 및 홍보 매체 등록 요구사항을 확인하세요.
- 사이트 상단에 제휴 고지문이 표시됩니다. 영상·SNS 게시물 등에도 해당 매체의 요구에 맞는 광고 표시를 추가하세요.
- 상품 가격은 수시로 변동되므로, 가격 정보가 불확실하면 0으로 설정하여 '판매처 가격 확인'으로 표시하세요.
- 쿠팡 API나 상품 이미지 무단 수집 기능은 포함하지 않았습니다.
- 쇼핑몰은 상품 소개/연결만 담당하며 결제·주문·배송 기능은 없습니다.
- 공개용 파일에 개인정보, 비밀번호, 쿠팡 API 키 등을 넣지 마세요.

## 로컬 미리보기
Python이 설치된 경우 해당 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000` 접속. 단순히 index.html을 더블클릭하면 브라우저의 파일 보안 정책으로 products.json을 읽지 못할 수 있습니다.
